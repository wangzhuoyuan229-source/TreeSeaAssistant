## 1 产品与视觉定位

以 [需求与算法规格](ios-app-spec.md) 为业务依据：仅 iPhone、iPad；iOS / iPadOS 17.0 起；中文；离线计算。主要功能采用 MAA 机制，未知诡秘候选采用 hlsh-helper，路标与羽瞰点补充交互。首版使用截图和人工确认完成地图、库存、候选集合及推荐路线闭环，不计算节点概率。

采用仅暗色的「幽暗空间、有机光域、手稿图谱」视觉语言。主题表现集中在插图、色彩、纹理和小范围装饰；导航、返回、输入、菜单和 Sheet 使用原生交互。

## 2 基础规则

### 2.1 语义色板

| Token | 色值 | 用途 |
|---|---|---|
| background | #0A1115 | 页面底色 |
| surface | #142126 | 内容面板 |
| surfaceElevated | #213238 | 高层级内容区 |
| textPrimary | #E9EEE8 | 标题与正文 |
| textSecondary | #A5B8B8 | 次要说明 |
| textMuted | #8A9E9F | 辅助文字 |
| accentPrimary | #90E4D7 | 操作与选择 |
| accentIllustration | #AEA4FA | 主题插图 |
| warning | #E6C77D | 待确认或提醒 |
| error | #F29494 | 错误与风险 |
| textOnAccent | #0A2220 | 青绿按钮文字 |

青绿表示选择及主要操作，紫蓝用于插图。风险必须附带文字或图标。文字不直接压在高频纹理上。常规面板以实色承托；仅当前选中对象、主题焦点和操作确认使用局部光晕。

这组可用文本色与三种实色背景的计算对比度最低约 4.74:1，主按钮约 11.3:1。该计算不代表生成图片、透明材料和所有运行状态已验收。

### 2.2 字体、间距、形状

- 使用系统字体接口；SF Symbols 仅用于返回、关闭、设置等通用操作，游戏专有图标使用原版素材。中文由系统字体承担。功能文字保持实时文本，支持 Dynamic Type。
- 默认字号：展示标题 34 pt；页面标题 28 pt；分区 20 pt；正文 17 pt；次要正文 15 pt；辅助说明 13 pt。
- 标题 Bold，分区 Semibold，正文 Regular；数值使用等宽数字；正文行距以约 1.45 倍为设计基准。
- 间距序列为 4/8/12/16/20/24/32/48 pt。iPhone 横向内边距 20 pt，窄窗口 16 pt；iPad 24–32 pt；阅读正文最大宽 720 pt。
- 内容面板圆角 16 pt，主题内容按钮 12 pt，标签胶囊形；原生控件保留系统形状。
- 点击区至少 44×44 pt；主要内容按钮默认高 52 pt；列表行最小高 60 pt，随字号增长。
- 主题插图默认高 180 pt，紧凑高度降为 120 pt，iPad 可至 240 pt。默认字号下首屏主要操作可见，大辅助字号允许滚动。

### 2.3 素材与装饰

素材依最新 V2 和用户要求分为两类：[图标](../图标/README.md) 保存路标原版图集与映射；[自建素材](../自建素材/README.md) 保存背景、应用身份及通用 UI。游戏对象不自创、不重绘、不换色。自建装饰包含动物骨骼版画、奔跑剪影、植物、紫蓝墨迹和赭金细线，动物只作页面装饰。地图底图低干扰，纹理停留在边缘和留白处，不遮挡节点、道路或候选文字。

版画纹理预生成，避免运行时持续全屏流动。iPad 封面使用动物与植物合并 v3，应用图标使用首次生成的三瓣徽记 v1；透明徽记不替代不透明 AppIcon。图库、账号、社区或商业化入口不进入首版预览。

## 3 导航与业务页面

主入口为「地图」「会话」「设置」。地图内提供「节点」「加工品」「路线」上下文操作，不把截图用途混为一个导入入口。

### 3.1 导入与地图确认

流程：选择用途 → PhotosPicker/文件导入 → 旋转与裁剪 → 选择楼层 → 识别提案 → 人工确认地图和资源 → 提交。

- PNG、JPEG、WebP 单图；超限、无法解码、取消、低置信度和提交拒绝均保留旧会话。
- 地图、背包、加工品详情、移动预览四种用途明确分开。
- 新提案与当前有效地图分开显示；只有确认后替换会话。
- 出生点、当前位置、出口和 AP 分栏确认；修改当前位置不能暗示出生点同步变化。
- 预览节点可修改类型、进度、道路与标记；未确认项使用警示标记和就近解释。
- 未确认道路不可绘制成可执行徒步路线；截图不完整时说明未采用全图约束。

### 3.2 库存与移动预览

- 同名物品按实例展示，件数、剩余次数、目录初始次数分别表达。
- OCR 1/7 歧义、缺失次数和仅图标结果保持待确认，不自动填目录初始值。
- 部分库存截图只更新确认覆盖的实例；重复截图不能累加次数；完整替换要求明确确认。
- 未显示希望/源石锭总额时写「未记录」，只列确认增量。
- 移动预览需确认目标、方式与实际 AP，成本覆盖只影响该动作。
- 随机落点物品可以录入，但明确不参与首版确定路线。

### 3.3 节点与候选集合

节点图形使用原版图标、线型和标签共同表示状态：已揭示为对应类型原版图标；待揭示和规则推断保留网站对应未知节点图标，推断另加实时文本；待人工确认附警示。不能用自创问号或动物装饰代替专有节点图形。

- 标题固定为「可能类型」，按 hlsh-helper 分类顺序展示候选，不标百分比或出现倾向排名。
- 展示出生点距离、距离/数量排除依据、全图约束状态与限制；视觉匹配分不进入候选列表。
- 唯一候选显示「按当前规则唯一」，仍标未揭示；禁止自动转换为确认商店资格。
- 多候选使用等样式列表；不绘制概率条或概率设置。
- 空列表、缺失规则、冲突或约束降级说明就近可见，不自动补回被排除类型。

### 3.4 必经、路线比较与步骤

- 必经入口为节点详情的「必须经过」；显示已选数量 / 8；无访问顺序编辑。
- 飞行越过图形不代表实际经过；当前节点与已完成空地按现有规格处理。
- 最多三条实质不同推荐；相同路线合并偏好标签，只找到一或两条时按实数展示。
- 路线标签使用「综合收益」「节省加工品」「较低战斗风险」。结果标题为「推荐路线」，评分为「预计收益分」。
- 路线摘要包含必经覆盖、AP 毛消耗/结束余额、加工品使用/剩余、确认增益、战斗代价与假设；不显示游戏成功率。
- 一次突出显示一条路线。徒步为沿道路的实线，飞行为独立曲线/箭头，附图例，不改变原始道路。
- 步骤表显示起止、移动方式、对应实例、使用次数、前后 AP 与确认增益。
- 预览和切换路线不扣真实资源；实际执行确认或新资源导入后才对账。
- 输入修改立即把旧路线标为「已过期」；旧结果可供查看，但不能呈现为当前有效结果。

## 4 组件与反馈

| 组件 | 变体和必要状态 |
|---|---|
| 按钮 | 主要/次要/文字/危险；正常、按下、禁用、加载 |
| 列表与节点 | 正常、选中、未揭示、待确认、推断、已完成、必经 |
| 表单 | 正常、焦点、缺失、错误；错误就近显示 |
| 内容面板 | 实色承托；标题、摘要、内容、可选操作 |
| 标签 | 分类、状态、偏好；选中含填充及标记 |
| Sheet/Menu | 原生关闭、完成、取消和焦点行为 |
| 数据 | 未记录、确认值、估计值、不可用明确区分 |

结果状态文案：

| 状态 | 表达 |
|---|---|
| 待确认 | 尚有字段需要确认，说明影响及修正入口 |
| 计算中 | 当前操作进度与取消；保留会话 |
| 旧结果 | 已过期，输入已修改，可重新计算 |
| 搜索穷尽并证明无解 | 当前条件下无可行路线，指出已知限制 |
| 预算内未找到 | 暂未求得路线，不能写无解 |
| 只找到部分推荐 | 已找到 N 条，保留完整路线并说明预算限制 |
| 取消 | 不覆盖最近有效结果 |

## 5 iPhone / iPad 适配与动效

按实际空间和 Size Class 组织，可用内容宽为当前容器宽扣除左右安全区及页面内边距，不使用设备型号或启动时屏幕宽。Compact、可用内容宽不足 680 pt 或辅助功能字号为单栏；Regular 达到 680 pt 支持列表（基准 280 pt）与详情（至少 360 pt），达到 960 pt 支持导航侧栏组成三栏（侧栏基准 240 pt）。iPadOS 17 使用系统分栏导航；支持新版可转换 Tab/侧栏的系统可采用原生转换。iPhone 横竖屏、iPad 分屏和窗口缩放保留选择、地图视口、滚动及未完成输入；窄窗口折叠，不裁掉功能。

地图支持缩放、移动、重置与节点列表替代入口。键盘出现时表单避让；触摸、指针、键盘操作均有清晰反馈。

自定义内容按钮按下缩放 0.98 / 100 ms，释放约 180 ms；选中状态约 180 ms；内容展开约 240 ms；封面首次局部显现约 420 ms，结束后静止；状态替换约 160 ms。原生导航及控件使用系统动画。动画可打断，操作无需等待演出。

Reduce Motion 使用静态或短淡入淡出；Reduce Transparency 使用实色承托。触感仅用于有明确语义的选择确认、成功与错误。

## 6 静态预览与示例

预览索引见 [ui-previews/README.md](ui-previews/README.md)，制作计划见 [ui-design-production-plan.md](ui-design-production-plan.md)。所有图使用合成示例，标「界面概念预览」，不是已运行截图。

统一示例：第一层、5×3 网格；初始与当前位置 N05；必经 N07（已完成空地）；出口 N09；AP=6。确认道路为 N05–N06–N07–N08–N09 及 N07–N12–N13–N14–N09，另有 N07–N02。N08 普通作战，N13 秘境行商，其余上述中间点为空地；N02 未知诡秘。

- N02 展示诡意行商 / 不期而遇两项合成候选，保持列表顺序、保留未揭示状态，不标百分比；不声明该图已经由实际规则推断。
- 路线 A：N05→N06→N07→N12→N13→N14→N09。6 条边、6 AP、余额 0、加工品 0 次、战斗 0 次；按既有权重示例，14−6−6×0.25=6.5 分。标签合并为综合收益 / 较低战斗风险。
- 路线 B：N05→N06→N07→N08→N09。4 条边、4 AP、余额 2、加工品 0 次、普通作战 1 次；0−4−4×0.25−4=−9.0 分。标签为节省加工品（同为 0 次时 AP 毛消耗更少）。
- 显示「找到 2 条不同路线」，两条均实际经过 N07；不凑第三条。
- 库存为标准引擎实例 A 剩余 1 次、实例 B 剩余 3 次；简易遥控器的 OCR 1/7 为待确认提案，不加入可执行库存。希望和源石锭为未记录。
- 徒步每条边 1 AP 是示例模型；路线 A 的资源台账为 6→5→4→3→2→1→0。示例不宣称实战收益或算法运行结果。

## 7 验收

静态检查涵盖布局、关键中文、候选/状态语义、路线与 AP 算术、库存实例、统一配色和设备版式。路线分是 App 适配权重示例，不能标为 MAA 原生策略输出。图片实际尺寸、最终提示词与已知限制记录到预览索引。

实施后另验：普通文本至少 4.5:1，必要控件边界/大文本至少 3:1；点击区至少 44×44 pt；最大辅助字号；VoiceOver；灰度、增强对比度、减少动态效果/透明度；iPhone 横竖屏及 iPad 窗口缩放；真实识别与计算取消。静态图不证明这些运行条件通过。
