预期：核对文件字节数/哈希、实际尺寸、透明通道、图集矩形、加工品映射、文档链接和计划状态，输出完整核验报告。

实际：脚本读取透明 PNG 的 alpha 后，再对同一 Pillow Image 调用 verify，触发：

```text
RuntimeError: verify must be called directly after open
```

这是核验脚本 API 调用顺序错误，不是图片损坏的证据。完整报告未输出，后续链接/计划一致性检查不能记为通过。此前两个透明 PNG 的单独 alpha 检查和素材保存清单仍保留。

建议修正：重新打开 PNG，立即 verify；尺寸与 alpha 在独立打开实例中读取。用户明确授权继续后，只修正核验流程并重新运行必要检查，不重新生成图片、不改变已选版本、不重复下载原版素材。

恢复结果：按上述方式分开打开实例后，脚本正常退出、报告 errors 为空；检查覆盖 11 张原版 PNG、76 个映射、12 组加工品配对、8 张自建 PNG、6 个 SVG、文档本地链接、12 个开发任务未勾选及 12 个 V2 色板参数一致性。图片没有重生成或替换，完整核验结果已保存。
