## 1 依据与目标

最新依据为用户提供的四张本地图片，且用户允许本次规划和预览借用部分原作元素。业务仍遵循 [ios-app-spec.md](ios-app-spec.md)，iOS / iPadOS 17.0 起、仅暗色、离线截图导入与人工确认、hlsh-helper 未知诡秘候选集合及多路线规划；不计算节点概率、不显示百分比。前端实施与 iPhone/iPad 适配任务见 [开发计划](superpowers/plans/2026-10-13-ios-screenshot-prediction-planning.md) 第 0.1 节及任务 1A、8、9、10。

这版将先前的青绿发光森林视觉收敛为参考图更鲜明的「异色自然史拼贴」：黑色不规则剪影、解剖版画、深青场景、紫蓝墨块、赭金几何线及多色光核。V2 的视觉规定优先于旧版 UI 规范的色彩、标题字体、面板外形和装饰描述；业务状态与示例规则保持一致。

## 3 视觉基础与组件

### 3.1 三个空间层级

1. **场景层**：暗青、苔绿、深黑，表现丛林/自然史氛围；普通工作页降低细节和亮度。
2. **拼贴层**：粗边墨块、骨兽剪影、赭金放射线和紫蓝笔触。只承担识别与层次，不遮挡地图关系。
3. **阅读与操作层**：近实色的深色阅读区、清晰正文、光域胶囊和原生系统交互。

### 3.2 色板

以下是本方案的设计值，不是原图逐像素取色结果。

|---|---|---|
| background | #060A08 | 深黑底 |
| inkSurface | #0B1210 | 文本与数据承托 |
| forest | #173B31 | 深青场景 |
| capsuleRim | #79BCAF | 胶囊边缘、选中轮廓 |
| ultramarine | #3348D6 | 粗笔触/插图 |
| violet | #7146B5 | 光核/版画异色 |
| ochre | #B99551 | 光核与几何线 |
| burgundy | #6B2938 | 封面局部异色 |

多色光核作用于图标、局部装饰和边缘；数据文字下方用稳定深色承托。风险、待确认、选择不能只靠色相区分。

### 3.3 字体、轮廓与间距

- 展示标题使用宋体/系统衬线气质，iPhone 28–34 pt；页面操作和正文使用清晰系统无衬线字体，正文 17 pt，次要文字 15 pt，辅助 13 pt。
- 标题点到为止，不把整页正文做成手稿字体。小型英文仅限有实际意义的编号/分类，不生成伪拉丁语装饰长句。
- 间距沿用 4/8/12/16/20/24/32/48 pt；iPhone 左右 20 pt，iPad 24–32 pt。
- 主要操作胶囊最小高 52 pt；会话与路线单元按内容增高，圆润轮廓接近参考图 4，正文排列稳定。
- 墨迹面板使用不规则外缘、规则内边距。点击区、文本区域、焦点框保持规则，至少 44×44 pt。
- 会话列表借用存档胶囊外观，但按真实会话数量显示，不写死六个存档，不新增游戏读档功能。
- 加工品借用「选中对象放大＋实例列表」图鉴版式，不新增收藏图鉴、剧情结局或 NPC 系统。

### 3.4 反馈与动效规划

原生返回、Sheet、输入、键盘与辅助功能行为保持平台习惯。自定义胶囊按下立即反馈，约 100 ms，释放约 180 ms；选中光域切换约 180 ms；信息面板约 240 ms 显现；封面初次拼贴显现约 420 ms 后静止。不设置持续全屏流动背景。

减少动态效果时采用静态/短淡入淡出；减少透明度时使用实色面板。iOS 17 以标准材料及预制装饰素材表达，新系统的导航材质由系统控件提供；静态生成图不证明真实系统材质已实现。

### 3.5 素材取用与已选版本

原版图标覆盖节点、加工品、路径符号和游戏标记，取 [图标清单](../图标/manifest.json) 的 `assetKey`、原始 PNG 与像素矩形，保留比例、颜色和对齐信息。小图与加工品详情插图分别使用；原版区域背景不是独立区域图标。SF Symbols 与自建 SVG 只用于通用操作，未知节点用对应原版未知图标。

自建背景必须有参考图中的动物元素：骨白动物解剖版画、奔跑剪影配合紫蓝墨块和赭金细线。iPhone 封面选 `iphone-animal-cover-v2.png`；iPad 封面选 `ipad-animal-botanical-cover-v3.png`，结合第二版上部动物与第一版下部植物边框。数据页可选低干扰植物背景，动物只放边缘、封面或留白；不进入地图语义、点击区或 VoiceOver 节点列表。

应用图标按用户选择使用首次 `app-icon-master-v1.png`，透明徽记仅作配套装饰。素材实际尺寸、alpha、校验值和真实提示词见自建素材索引；不拉伸动物，窄窗口使用另一构图或植物底图＋透明动物图层。文本仍为原生实时文字，近实色承托；按显示尺寸解码缓存，避免同时加载所有高清图集。设备内存、可读性与裁切尚未验收。

## 4 本轮四页规划

### 4.1 iPhone 会话首页

上方为衬线「黑流树海」标题与紧凑紫蓝骨兽拼贴；下方是青绿边缘、彩色光核的「继续探索」胶囊，显示第一层、AP 6、必经 1/8，主要动作「恢复会话」。地图与资源截图导入是两个独立入口，保留「新建会话」和本地会话入口。底部主导航为地图/会话/设置。

首页具有最强的主题插图。默认字号下恢复/导入操作首屏可见；不设置必须播放完的开场，不为场景插图新增剧情。

### 4.2 iPad 地图工作台

宽窗口三栏：薄导航栏、主要地图、右侧节点/路线检查区。场景只在边缘与留白处，地图区域采用黑墨承托、原版图标、清楚编号与道路。节点检查区展示 N02 未揭示状态、两项合成候选及排除依据，不显示概率或百分比；「路线」为相邻切换入口。上方可见第一层、AP 6、截图导入与撤销。既有预览的两项 50.0% 属于过期内容，不作为实现要求。

地图初始/当前位置、必经、出口、未知节点必须可辨认。装饰线为低亮度赭金细线，不可与实际道路混淆；飞行箭头不改写原始道路。按 UI 规范第 5 节的可用内容宽与 Size Class 判定，680 pt 起可双栏、960 pt 起可三栏；Compact、窄窗口和辅助功能字号使用单栏，保留选择、地图视口与编辑草稿，不强制 iPad 横屏。

### 4.3 iPhone 加工品确认

借用图 4 的选中对象光域与图 3 的黑墨说明区：上半部使用标准引擎的原版加工品详情插图，下半部显示实例 A 剩余 1 次、实例 B 剩余 3 次。简易遥控器 OCR 1/7 独立置于待确认行，配原版小图。主要动作「保存已确认项」，辅助「手动添加」。

不将两件同名物品合并成目录次数，不把未确认提案加入真实库存。部分截图的覆盖范围提示可见。既有 AI 物件示意图保留为历史构图，正式展示替换为原版资源；展示插图不能冒充已验收识别模板。

### 4.4 iPhone 路线比较

标题「推荐路线」，明确「找到 2 条不同路线」。两个宽胶囊参考图 4 的存档单元，显示偏好、预计收益分、AP 消耗/余额和加工品消耗。A 合并综合收益/较低战斗风险标签，B 标节省加工品。摘要与操作旁显示「按当前估计可执行」。

不展示成功率、不凑第三条、不写全局最优。点击查看/切换方案不消耗真实资源。候选的未揭示属性、规则资料冲突和旧结果失效规则继续遵循业务规格。

## 6 制作顺序与验收

1. 写入本规划与逐图提示词，再出图。
2. 使用内置 imagegen，把四张本地图片作为风格参考，每页独立生成大幅单屏图。
3. 本轮先交付首页、地图工作台、加工品确认、路线比较四张图；其余七页待后续安排。
4. 逐图检查参考风格、主要中文、资源台账、实例区分、地图拓扑、路线差异和状态语义。
5. 保存图片、实际尺寸、最终提示词与检查记录。旧稿不覆盖，原参考图不修改。

生成失败或实质业务偏差按用户的遇错暂停规则处理。正文、动态字体、点击区、VoiceOver、真实材料和性能，须在将来的实际 App 中验证；本轮不创建工程或前端文件。
