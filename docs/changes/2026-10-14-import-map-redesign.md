2. 地图按最新 1490×894 参考的 220px 网格、原点(236,186)统一缩放图标、文字、道路与命中位置；使用原版分层背景、圆形图标、细流道路、透明旅人；保留节点ID、选择、必经、路线、缩放与平移功能。iPhone 保持可读，支持横屏放大；iPad利用宽屏。
